Terms of use

HubSoft STOCK Export is a personal automation operated by the owner of this GitHub account. It is not a service offered to the public and provides no public account registration, paid subscription or commercial support.

Authorized use

The workflow is intended only for the operator's authorized HubSoft account and Google Drive destination. The operator is responsible for having permission to download and store the reports and for complying with the applicable HubSoft, Palladium, Google and GitHub terms.

Operation and availability

The workflow depends on third-party services and may stop when authentication, website layouts, permissions or service availability change. Scheduled execution may be delayed. The operator should check exports before relying on them and review failed runs in GitHub Actions.

Stopping the workflow

The operator can disable or delete the workflow and revoke Google authorization at any time. Existing Drive files remain under the owner's control.

Data handling

Use of report data and Google authorization is described in the privacy policy. This website provides information about the automation and does not itself execute exports.
