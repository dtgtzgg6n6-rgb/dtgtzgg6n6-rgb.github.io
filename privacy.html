Data use

Privacy policy

This policy describes the personal HubSoft STOCK Export workflow operated by the owner of this GitHub account.

Information accessed

The workflow uses the owner's HubSoft credentials to download four designated footwear reports. It uses Google OAuth authorization with the drive.file scope to access the destination folder expressly selected by the owner and files created by the app. It reads folder permissions and export metadata, such as file names, sizes and checksums, to create and verify uploads and avoid duplicates.

Purpose and processing

Google user data is used only to deliver, verify and maintain the requested report export. Report files are processed temporarily on a GitHub-hosted runner and saved in the selected Google Drive folder. They are not intentionally published on this website or included in GitHub workflow logs or downloadable workflow artifacts.

Credentials and retention

HubSoft credentials and the Google refresh token are stored as encrypted GitHub Actions repository secrets in the owner's private automation project. Workflow code can use those secrets during a run. Local setup copies may also exist on the owner's computer. The owner controls their retention and removal. Temporary runner files are discarded with the runner. Drive archives remain until the owner deletes them.

Sharing and limited use

Data is processed by Google and GitHub as required to operate the workflow. The workflow does not sell Google user data, use it for advertising, or send it to AI models for training. Its use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Owner controls

The owner can disable the GitHub workflow, remove its repository secrets, revoke the app's Google access in Google Account connections, and delete stored archives from Drive. Revoking access stops future authorized Drive operations; it does not delete existing archives.

This information website

This static website has no forms, app analytics or advertising scripts. GitHub Pages hosts it and may process ordinary request information under GitHub's privacy statement.

Contact and changes

The operator is identified through the project's GitHub account. This personal tool is not offered to external customers. Material changes to data handling will be reflected on this page.
